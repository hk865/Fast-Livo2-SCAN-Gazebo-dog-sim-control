# 本地源码与配套产物打包

在文档PDF已导出后，于源码根执行`python3 -B tools/package/build_delivery.py`。输出一套源码和必要资产、中文文档、配套install三个压缩包及独立PDF；不发布到网络，不把build/install/runs/.local或实施记录放进源码包。

源码包使用实际文件遍历，因此不会因Git忽略规则漏掉Student或L1网格。脚本检查关键算法/资产、私有宿主引用、可疑秘密标记、软链接及压缩完整性；这些有限检查不等于权利审查或全面秘密扫描。SHA发行清单只校验文件完整性，普通启动从不读取它。

配套install包不带体积较大的分离调试符号，不含公共系统环境。跨平台优先使用Dockerfile从源码重建，不能把相同Linux文件名等同于ABI兼容。全部材料的公开边界见[资产来源](../../docs/资产与来源.md)。
