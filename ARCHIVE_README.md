# Go2 Teacher code and experiment archive

This is one archival branch. The existing public C44 source/docs commits remain unchanged in its ancestry and original locations. `history/code/` is the current reconstructed snapshot; use the archival commits to inspect changes. `history/experiments/` contains one small result/provenance record per stored run.

New commits are created at archival time by **Codex archival reconstruction**. They are not original experimental commits or claims about the original author. Experimental labels/times are preserved as evidence; unzoned directory times are not assigned an invented timezone. Missing snapshot/metadata coverage is explicit. No continuous complete development history is claimed.

Code bytes are checked against saved source-manifest SHA256 where available. Personal home paths, chat/Page/session identifiers are redacted; original and archived hashes are recorded separately. Redacted contracts and omitted private authorization, dependencies/assets/weights mean this is not a turnkey frozen-run reproduction. A summary does not recreate original data.

No raw sensor streams, videos, NPZ/weights, native binaries/build outputs, PDFs, credentials or unrelated records are uploaded. Each excerpt is a few trailing log bytes and is labeled as such. All original data remain on the user's computer until an itemized deletion approval.

## Reading a change

`git log -- history/code` and `git diff <old> <new> -- history/code` show the reconstructed code changes. Read the same commit's experiment JSON to distinguish actual motion, source admission, partial region progress and strict mission acceptance. A succeeded segment, complete archive or 46 region receipts alone is not complete navigation PASS.
