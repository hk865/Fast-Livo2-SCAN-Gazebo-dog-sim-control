# 总编排

读取各模块配置，生成一次run和统一环境；唯一入口管理锁和launch退出。

## 输入与输出

| 输入 | 数据/语义 | 输出或消费者 |
| --- | --- | --- |
| 用户CLI、各模块settings | 静态配置/启动选项 | 同一run、统一env、唯一总launch |
| SIGINT/子进程退出 | 生命周期事件 | 只关闭自己拥有的组件，记录退出码 |

名义频率、坐标与因果关系见[模块数据流](../../docs/模块数据流.md)，源戳不能用保存时间代替。

## 核心代码与配置

- 入口：`main.py`。
- 子入口：`launch/demo.launch.py`；日常使用根`start.py`，不重复启动已有模块。
- 参数：`config/navigation.json 与 config/settings.json`；保留原控制、freshness、几何与停车阈值。

## 使用与调试

先在根执行`python3 start.py --check`查看完整缺项；构建按[移植说明](../../docs/移植构建运行.md)。日志、当前状态和各进程退出记录写入当前`runs/`目录。诊断实现位于根`experiments/`，正常入口不加载它们。具体故障先沿本模块输入来源、时间/坐标代次和输出消费者检查，不能把所有错误归因于DDS。

本轮移植验收状态统一见[验证状态](../../docs/验证状态.md)，构建/组件测试不等于导航通过。
