# 异步后端当前实现

Building 使用 `building_runtime.py` 作为唯一 `map→odom` 修正出口。前端局部 odom 连续，后台不回写 ESIKF；旧 `known_scene/localization_runtime` 不与该出口并行启动。

`snapshot_bridge` 在 LIO/VIO 同测量戳最终更新后复制自有快照，最多4096个 LiDAR 末时刻点。提交使用预分配有界 SPSC，后台线程写有界 spool；独立 Python 进程读入、存关键帧/子图、配准与优化。复制时间与后台完整耗时分别记录，不能混称为实时延迟。

外部地图读 XYZ 或 XYZ/RGB PCD；无需历史采集位姿。`ExternalMap` 提供空间分块和索引。实际 Building 测试采用配置的出生位置/朝向先验与 `PriorTracker` 局部配准，不是无初值全地图重定位。地图固定 AABB 处理覆盖外点，体素粗 ICP 加稳健点到平面细化，独立留出点、覆盖率、观测性、歧义和两帧一致性门限共同验收。在线模块不读真值；真值仅在实验结束后的固定坐标、原时间戳评分中读取。

`History` 存自有关键帧、相邻 odom 边与实际 NPY 子图。自动回环每8关键帧检查，需时间分离20帧且实际 odom 行程至少5m，历史候选要经真实历史点云几何验证及第二帧一致确认。验证通过才加图边。`native/graph_solver.cpp` 采用 SE3 稀疏图、最多80活动节点/8次迭代、旧节点固定和有界步长。无已知地图时仅通过同一结果通道提出图修正；已知地图模式由地图几何结果决定修正，不叠加第二套图出口。

已验证：无轨迹地图/持久化/修正/有界队列业务测试；65帧（含静止后续）合成行程触发两次几何验证、原生图优化与唯一修正提案，静止采样不被当成回环。Building 真值旁路采集已实测局部配准，固定坐标3D RMSE约3.22cm；它属于真值控制实验，不能算真实SLAM导航通过。

已实测：配置出生先验下85.70m真实SLAM完整导航、独立实际回环与运动中短断流恢复，见 [验收摘要](../../../docs/Building后端验收摘要.md)。仍未完成：粗范围多候选时序初始化、一般失跟/绑架恢复、无初值全图定位和通用稳定性；真正fixed-lag/IMU因子未实现，未重写ESIKF。历史SE3图不等价fixed-lag。
