# 异步后端说明

本目录已接入Building ROS/Gazebo主链；早期独立原型状态不代表当前实现。请以[当前实现说明](README.md)、[Building模块说明](../../../docs/Building模块说明.md)和[验收摘要](../../../docs/Building后端验收摘要.md)为准。

坐标`T_AB`把B映入A；保存的是LiDAR测量末时刻点云及对应`T_odom_body`、`T_body_lidar`。地图无需采集位姿链。当前实测使用出生先验局部匹配，非无初值全图定位。

快照/提交有界；主线程不做地图配准、全云JSON或同步落盘。驻留历史上限2000关键帧；超限报错，分段/懒加载未实现。图是pose-only SE3，非紧耦合滑窗。更多边界见上述当前文档。
