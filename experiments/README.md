# 实验与历史材料

这里保留从正常运行链分离的候选与诊断实现，避免按R编号盲删。它不是第二套正式导航，也不是日常启动的依赖。根`start.py`只读当前模块配置；115个应用模块导入检查不加载本目录。

- `diagnostics/`：原R系列探针、计时和观察类。
- `candidates/`：未选中的控制/Teacher/运动测试方案，不能当当前行为。
- 旧profiles和目录迁移说明仅在本地开发材料保留，不进入公开源码/发行包。
- `recording/`：旧原始记录辅助。

部分旧脚本引用已退役数据或旧合同，仅供阅读，不承诺可直接运行；不要从这里恢复历史hash启动门禁。可用的独立验收入口在`tools/validation/`，不读旧PASS或向机器人注入真值。
