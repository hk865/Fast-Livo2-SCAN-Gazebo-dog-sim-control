# 实验证据保留与原始数据清理边界

用户已明确授权删除原始实验数据以释放空间，并要求保留实验报告和可复现源码。清理范围、实际删除结果和最终保留文件以本仓库根说明、[evidence索引](../evidence/INDEX.md)及[证据库存](../evidence/EVIDENCE_MANIFEST.json)为准；本文不把清理计划冒充已经执行的删除记录。

精简证据目录为`evidence/{reports,receipts,curves,figures,history_manifests,reproduction_checks}`。主要运行分组是`V12_fbcb`、`V18_prefix_ac02`、`V18_full_ab53`、`V17_efde`和`height_failure_6fdf`。其中每0.2s的telemetry/SLAM派生JSONL和PNG只供曲线展示；不是完整200Hz安全、接触、关节目标/力矩、源因果或逐次publication验收输入。最终清单应保存来源、复制SHA、用途和抽样边界，不能把派生文件标为全raw替代。

## 保留内容如何解释

| 类别 | 保留用途 | 能否替代原始实验输入 |
|---|---|---|
| 源码、world/模型资产生成规则、配置、协议、验收器、预检脚本 | 审查实现、重建新环境、运行新实验 | 不能恢复旧运行中全部输入/时间顺序 |
| 训练契约、冻结模型身份、checkpoint来源与SHA | 防止误用另一模型，复核观测/动作语义 | 若权重未包含，SHA本身不是权重；按仓库说明另行取得同字节模型 |
| 报告、独立收据、小型指标、失败解释和版本关系 | 记录当时按何种门得到什么结论 | 不能重新计算全部控制、接触、SLAM、provider和发布链门 |
| 历史清单/SHA、实际加载库与来源记录 | 标识当时文件字节、发现保留文件变化 | SHA不是文件内容，不能从SHA恢复已删数据 |
| 原始200Hz物理、ROS消息/云数组、图像、观测动作、详细二进制/JSONL | 当时独立重放与审计所需完整来源 | 删除后相应原始重放能力失效；不得默认由摘要补齐 |
| build/install/log、私有旧二进制 | 本机当时构建与加载证据 | 新构建可能因工具链不同改变字节；要重新验证，不继承旧PASS |

本仓库不声称保存完整、可从头独立验收的历史实验包。原实验目录名、原绝对路径、历史外部库存与哈希是来源标识，**不是保证仍存在的下载链接**。旧报告保留“当时未删除”“保存全部日志”等历史措辞时，应按该报告日期理解；当前清理状态以最终库存为准。

## 哪些结论还能说，哪些不能说

可以说：当时独立验收得到V12/V18指定静态32区域、两条完整12m坡道与固定5s停车限定通过；V17接受31615/提交31614/取消1严格失败；旧Sim2Sim和历史失败保留。这些是历史验收结果与归档身份。[总实验报告](EXPERIMENT_REPORT_20261006.md)给出范围和关键数字。

不能说：只要收据JSON与SHA还在，就已经重新独立审核原实验。严格重审还需要每份收据的原始输入、原冻结来源/二进制、完整provider状态、发布账本、几何和时间链等。某个required输入删除、缺失或字节不符时，验收器应FAILED或UNVERIFIED，不能用0、保留摘要、反推值或Gazebo真值填补。

原common/publication/ramp的UNVERIFIED状态与新增metadata-v2联合结果分别保存和解释；新的关联审计没有回改原收据。零取消失败、未完成前缀、缺证据失败和未验证分支不因为清理而转成通过。有限单轮通过不延伸为全局鲁棒性、完全传感器Actor、严格跨引擎Sim2Sim或真机通过。

## 新实验的可复现流程

1. 从本仓库固定commit构建，并按根README准备ROS/Gazebo、FAST-LIVO2/SCAN、模型和资产依赖。旧build目录不是新构建证明。
2. 取得冻结Teacher同字节权重，校验模型SHA；核对247维语义、关节名称、默认姿态、PD/DC限幅和50/200Hz周期。
3. 路径、库、配置与冻结预检指向旧本机时，在新实验版本显式重建并重新冻结来源；不偷换旧收据的绑定，不直接复制PASS让启动门通过。
4. 使用新run、新ROS/Gazebo分区、唯一执行器；保持实际SLAM导航与Actor特权来源的区分。先前缀、后完整路线，复核300ms双时效、每次publication、接触和原始三维区域到达。
5. 运行前确定原始数据预算及诊断窗口；保留足以支持新验收的全部required输入。有限摘要不能代替完整证据，详细窗口外缺失内容标N/A。
6. 结束后等待所有writer退出，检查队列/发布/诊断完整性，再计算源/配置/模型/实际加载库及结果哈希。保留失败与未验证，按新数据生成新独立收据。

重跑是新的实验，不会恢复已删除旧输入，也不保证新机器轨迹或二进制逐字节相同。不得用新实验成功覆盖历史失败或声称完成原实验的精确回放。

## 清理责任与范围

清理只涉及本次授权的实验raw和可重建构建产物，实际结果另记录；训练checkpoint、另一任务训练/评估、旧通过相机Demo以及本次保留源码不应混入清理。最终清理后应记录保留/删除根目录、文件数量和字节、是否存在未删除项；不要把旧全文件库存误当清理后仍有这些payload。
