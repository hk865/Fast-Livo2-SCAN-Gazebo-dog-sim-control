# 配套编译产物的使用边界

配套runtime-install压缩包包含本轮从源码新编译的SDK、FAST-LIVO2、SCAN、actuator、writer helper和patched Fast DDS，保留相对软链接、开发头/导出文件和许可证。体积较大的DDS分离调试符号不放入运行包；本地构建目录仍保留它们。它不包含ROS、Gazebo、PyTorch及系统动态库，因此不能替代公共依赖环境。

本轮构建平台为Linux x86-64、Ubuntu24.04、ROS2 Jazzy、Gazebo Harmonic（gz-sim8 8.15.0）、CPU PyTorch2.7.1。精确系统软件包列表见build_environment.tsv，固定源码下载见install/build_sources.json。公共软件源随时间更新，默认Docker基础标签也可更新；本包未宣称逐位可复现整个OS或兼容任意ABI。

推荐使用源码包内Dockerfile重新构建。在相同公共环境中复用这些产物时，将压缩包内install目录合并到源码根的install，再执行`python3 start.py --check`；本轮验证的容器根为/workspace/navigation。常规运行使用local_setup和当前源码根解析路径，不读取旧机器.local。换宿主系统/架构/ROS/Gazebo版本应重新构建，不能靠改库路径承诺兼容。

发行摘要中的SHA仅核对压缩包和资产完整性，不是日常启动门禁；无需旧run、历史PASS或源码版本批准文件。完整场景验证和最终镜像检查的具体范围见验证状态.md。
