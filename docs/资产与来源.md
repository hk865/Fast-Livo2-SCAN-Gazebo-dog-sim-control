## L1网格的下载与来源边界

当前Building场景必需`assets/meshes/L1_4D_Lidar.dae`；SDF同时引用它的视觉与碰撞几何，缺失会由`start.py --check`报告。本分支保留引用和原碰撞配置，通过外部链接补齐，不将DAE重新分发到本分支。

- 已核实的对应上游文件：[`unitree_go2_description/meshes/L1_4D_Lidar.dae`](https://github.com/khaledgabr77/unitree_go2_ros2/blob/0563d113870dde08a2a60a594130278559cd48b0/unitree_go2_description/meshes/L1_4D_Lidar.dae)，仓库`khaledgabr77/unitree_go2_ros2`，固定提交`0563d113870dde08a2a60a594130278559cd48b0`。
- [该添加提交](https://github.com/khaledgabr77/unitree_go2_ros2/commit/0563d113870dde08a2a60a594130278559cd48b0)于2025-05-08将此路径标记为新增，说明为“add 3D Lidar VLP16 and 4D Lidar L1”。原始文件下载地址已通过HTTP成功响应核实。

```bash
# 在本项目根目录执行；已有同名网格时保留，不覆盖。
mkdir -p assets/meshes
if [ ! -f assets/meshes/L1_4D_Lidar.dae ]; then
  curl --fail --location \
    'https://raw.githubusercontent.com/khaledgabr77/unitree_go2_ros2/0563d113870dde08a2a60a594130278559cd48b0/unitree_go2_description/meshes/L1_4D_Lidar.dae' \
    --output assets/meshes/L1_4D_Lidar.dae.download &&
  mv assets/meshes/L1_4D_Lidar.dae.download assets/meshes/L1_4D_Lidar.dae
fi
```

手动方式：打开固定提交文件页面，下载原始DAE，放入以上项目内路径；保留已有同名文件。下载不会替代依赖构建和导航验收，也不应覆盖原网格去继承既有PASS。

来源证据边界：当前工程的文件由旧模块化发布工程迁入，与旧发布目录及公开main中的文件内容一致；既有资产说明另记录了其与上述上游文件的对应关系。未找到最初从该仓库下载的直接回执，所以这里提供的是已核实可取得的对应上游文件，不能把它说成已证实的最初下载渠道或宇树官方DAE。提交者也不等于原始CAD作者，DAE仅标注“Blender User”。
