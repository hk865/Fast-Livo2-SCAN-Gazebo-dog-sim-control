# 粗初值局部配准：实际关键帧离线收敛域评估

当前运行方式使用配置出生位姿作为单一地图先验，再用局部点云配准跟踪小漂移。它不是在一个宽位置/朝向范围内维护多个候选，再随行动自动消歧。完全无初值全图检索仍未解决，但本阶段优先评估有粗范围的初始化需求。

## 评估方法

源数据为`runs/slam_multi_floor_repeat_20261030`保存的真实FAST-LIVO2关键帧，选择7/35/160/225/335s附近五个已接受地图配准帧，覆盖不同楼层/楼梯/走廊几何。每帧55种扰动，共275次。每次都从该帧已接受解附近独立扰动，不是仅在第0帧给一个误差后沿整段轨迹连续运行；因此不能据此声称“随着行动会自动收敛”。初值中心取实际已接受的地图匹配结果，**不是GT**；分别扰动地图XYZ和yaw，沿用同一地图、缓存、体素、粗ICP/点平面细化、holdout、观测性、歧义及增量门限，未放宽任何运行阈值。

所有275次匹配决定结束后，才打开原时间戳GT做固定坐标三维位置/姿态评分，没有拟合轨迹对齐。独立“准确”评分定义为位置≤.10m且姿态≤.05rad；这只是报告指标，没有替代运行时几何验收条件。五个场景样本很少，下表是测得计数，不是泛化成功率或保证捕获半径。每一档分母都是“总尝试”，不是只在已接受样本上的比例；正确+错误接受=几何接受，接受+拒绝=总尝试。“错误接受”指未达到本报告10cm/.05rad独立评分，包含略超10cm边界和严重错层，不意味着114次都为灾难性错层。

## 现状与缺口

- 当前0.5m/0.2rad限制是“每次配准结果相对给定先验的允许改变量”，不是初值实际捕获范围。结果靠近错误先验也可能满足该限幅。
- 单帧fitness/RMSE/观测性合格，不等价于全局位置正确。实际录制场景会有局部极小值与重复楼层几何。现有单帧歧义检查只能比较它实际生成的有限seed。
- 两帧TemporalAdmission检查修正一致性、时间间隔和源龄；它接收的是单帧已经选出的唯一结果。它没有维护多个位置/楼层/yaw假设的历史后验，不能靠“多等两帧”保证消除持续一致的错误假设。
- 现有历史SE3图使用相邻odom/几何loop边；没有把多帧地图匹配作为绝对地图因子联合求解，也没有多个初始位姿分支的后验。因此不能用已通过的回环优化代替粗初值多帧消歧。
- 已完成的短断流测试是在同一已建立定位附近恢复原传感器源，局部odom未重置；不是有米级/yaw大误差或楼层错误时的重定位验收。已披露的约60–80s单层初始化歧义等待也保留。

粗范围初始化适合下一阶段：在明确给定的XYZ/yaw范围内做候选检索与粗到精几何，跨真实连续帧保留并比较候选，在不确定时继续等待/停行，证据充分后才通过现有唯一修正出口。该多候选时序初始化目前未实现；此报告也没有为扩大范围放松运行门槛。全图盲检索研究脚本未运行、未集成，已按当前用户关注暂停，不阻塞导航阶段的已授权工作。

## 错层是否进入了在线导航

这275次只调用单帧`PriorTracker.localize`；没有调用TemporalAdmission、BackendResultReader或在线修正owner，没有把扰动结果发布给导航。四个Z±1.5m错误结果是**单帧registration接受**，不能称为在线两帧确认后接纳。

当前在线还有两层检查：TemporalAdmission要求两帧、间隔≥150ms且C一致≤.15m/.08rad；唯一owner还要求结果源龄/墙钟龄≤3s、同源pose关系有效、序列/epoch合法，以及相对当前C的增量≤.5m/.2rad。这些规则没有GT纠错、楼层标签真值或多候选历史后验。

对四个Z±1.5m单帧接受结果，用**该源帧实际已发布的C**离线回放owner增量门槛，平移变化分别1.483/1.516/1.626/1.617m，均超过.5m，都会被这一门槛拒绝。这个结论只是在已有正确附近修正状态下的数学回放，不是在线故障注入或两帧链路实测。

另一个现状是：首次localized后，owner对新提案失败不会自动撤销localized或停止发布前端pose/cloud；导航的300ms保护针对前端来源新鲜度。对于“前端继续刷新但地图配准持续失败/退化”的情况，目前没有完整的地图失跟停行、候选重定位与恢复状态机。因此运动中断流测试不能替代定位置信度/任意失跟保护验证。

保护也有明确边界：若初始C/先验本身就在错误楼层，或误差在较小增量内持续一致，以上规则不保证排除错误。已有275次数据中，114个独立评分未达标的单帧接受结果，有42个按该源帧C回放仍在owner的.5m/.2rad增量范围内；它们仍未经过两帧确认/reader/真实owner，不能说42个已经被在线消费，也不能声称增量门槛足以保证粗初值定位正确。

[逐项计数与owner门槛回放](backend_evidence/prior_capture_guard_audit.json)记录完整公式输入和结果。此项评估只核查现有实现，没有改门槛、重写全局定位或执行未授权研究。
