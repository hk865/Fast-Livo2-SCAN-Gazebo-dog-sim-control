## 预先冻结的判据与测试条件

`tests/protocol.json` 和每轮 `sources/tests/protocol.json` 归档：roll/pitch≤0.65 rad、机身离地≥0.18 m、无机身接触；线速度RMSE≤0.15 m/s、偏航RMSE≤0.18 rad/s、横向串扰RMS≤0.12 m/s、偏航串扰≤0.18 rad/s、请求轴响应比例≥0.4。停车等待3 s后连续评估，位移漂移≤0.15 m、偏航≤0.20 rad、线速度RMS≤0.08 m/s、偏航速度RMS≤0.10 rad/s。上下坡进度≥1.5 m且有真实坡面接触；低台阶到达x≥8.4并机身稳态升高≥台阶高度的60%，四脚实际登台支撑。

正式运动活动始于 `20261003_193541_stand_r1_bc7f`，结束于 `20261003_195120_step10_r3_18d2`。14项×3次不同进程，每次生成独立world/transport分区。50 Hz Actor，200 Hz真实关节物理，0.1 s默认姿态PD引导，然后持续Teacher；3 s开始命令，单命令11 s停止/18 s结束，台阶14 s停止/25 s结束，切换26 s结束。停车全程继续Teacher零速度控制。固定名义初态/种子，没有训练随机化、外力push或观测噪声；三次轨迹数值相同，不能当作广泛鲁棒性样本。

平层spawn为(6,−0.7,0.4)，避开原点上层楼板；上坡从(4,2,0.6)开始，下坡从(8,2,1.0)、yaw=π开始。台阶为x=7至9的实际碰撞平台，5/10 cm高。未移动原场景建筑或覆盖原模型文件。原点另做了实际适用性验证，没有用平层受控点的成功掩盖原导航起点的失败。

## 原导航起点：实际场景失败

Gazebo `runs/20261003_194022_stand_original_origin_r1_dc76`，spawn(0,0,.4,0)，真实相机与物理日志：初始187射线中102列击中上层楼板，输入扫描最小−1。零速度Teacher在2.02 s结束，最终机身高度.102985 m、roll2.102 rad、横移−.550685 m、偏航.93653 rad；机身接触、执行器故障锁定和阻尼处置真实记录。该轮接口运行完整性也失败，不能混入健康42轮接口通过收据。

Isaac `runs/isaac_cpu_original_origin_20261003_h` 使用相同完整静态几何实际碰撞与ray mesh，冻结Teacher输入；61帧/1.22 s触发实际跌倒诊断，最后测量离下方支撑面.14754 m、roll−.72168 rad、平面位移.54688 m。初始射线同样102列来自floor_3、85列来自floor_1，raw高度范围−2.5至−.1。

此诊断显式禁用了训练原有的扫描式base_height提前终止，以观察实际物理失稳；独立从base下方射线测离地高度，不改变247输入。训练原termination函数对首帧会立即判高度非法的证据是**录制张量上的反事实回放**，不是默认训练环境已真实运行15 s。原起点是失败结果，不是通过或完整默认环境rollout。

两环境初始上层击中与实际失稳说明场景/策略适用性需要解决，不能仅归因于Gazebo PID。碰撞、质量和求解器差异仍存在，不宣称上层扫描是唯一因果。当前保持冻结输入语义，未用脚下扫描、人工全高常数或真值导航改写结果。

## 执行器与异常保护

唯一执行器插件写12个 `JointForceCmd`；50 Hz策略同步，200 Hz PD与DC限幅。真实接触来自Gazebo ContactSensorData，q、qd来自物理关节，tau为已限幅写入的实际ForceCmd。它不是硬件力矩测量。COM线速度使用真实惯性偏移，不是link原点速度；坐标变换数值核查误差≤2.22e−16。

`test_results/native_actuator_audit/audit.json` 保存正常、200 ms无回复、NaN目标和同时出现另一个关节控制器的实际Gazebo审计。正常201物理步/51交换，周期误差约浮点精度，速度相关DC力矩裁剪误差0；故障3/4锁定，竞争控制器故障8且不接受IPC。它是执行器接口/保护测试，使用固定目标mock不能称Teacher运动测试。

停车最初冻结目标的失败、初始化过长在坡道跌倒、台阶指令太短未达终点、Ogre2/Mesa渲染崩溃和评估器序列化故障均保存；修复后的正式协议没有降低数值门槛。历史支持保持轮次重新评估为辅助/覆盖不全，不再作为Teacher停车通过证据。渲染崩溃未进入物理步时区分基础设施失败与策略跌倒。

## 传感器、导航与浏览器

IMU可提供body角速度，姿态可构造重力；完整JointState可提供q/qd；上一动作、速度命令和应用力矩是控制器内部量。SLAM twist需要机身原点→COM杆臂修正及因果时间核查；局部点云的最高**可见**点不能保证训练+20 m射线最高表面，遮挡、缺列、楼板和动态障碍仍是未解决语义。传感器旁路不切换Actor输入，缺失SLAM/注册点云必须标未验证，详见 `docs/OBSERVATION_REPLACEMENT.md` 和实际sensor shadow目录。
