# V7 实际高度故障：东墙被错误表示成近水平面

对应实际运行 `20261005_175143_closed_loop_cascade_height_diag_baseline_r1_6fdf`。本审计只读冻结运行和源码，使用 Gazebo 真值做离线几何验收；没有把真值输入导航，没有改 C++、运行模式或保护门槛，没有启动新仿真或操作其他任务。

已有证据支持一个具体原因：**真实竖直东墙的早期单扫描线簇，通过只判断最小特征值的平面条件，被建成法线近竖直的“水平面”；地图达到点数上限后冻结。机器人后来靠近该墙，较完整的墙面测量仍被关联到旧的错误平面，向下的高度残差进入 ESIKF，并通过状态协方差更新垂向速度。** 这不是机器人实际下降二三十厘米。该链条已由一次实际日志和独立几何核对直接支持；还不能把某个修复的效果称为已验证。

## 1. 先处理坐标系

LIO 的 `plane_center` 与 `point_world_iter` 实际在 `camera_init`，不是 Gazebo world。不能直接把地图 x≈17.4 与 SDF world x≈17.4 对比。

采用运行冻结的传感器 yaw 轴旋转，以及 6.799999999 s 最后初始化配对时刻的 SLAM body 位置和 200 Hz native body 位置，离线反变换：

`p_world = R_camera_init_from_world.T @ (p_camera_init - p_slam_anchor) + p_native_anchor`

anchor native world 为 `[1.19833148, 2.01589663, 0.32123459]`，SLAM body anchor 为 `[-0.00308486, 0.01658624, 0.00575360]`。实际 IMU 在 body 的平移是 `[0,0,0]`，不是猜测的 1 cm。另用该时刻完整姿态配对做敏感性核对；它对这些中心的 x 结果只改变约毫米，仍贴合东墙。此对齐只用于本离线报告。

实际嵌入 `world.sdf` 中 `wall_18.5` 的中心 `[18.5,3.5,2]`，盒体 `[0.2,14,4]`，室内面 **world x=18.4，y∈[-3.5,10.5]，z∈[0,4]**。实际静态模型均在 world 内嵌，未使用外部 include；审计解析全部静态 visual box，最近有限面比较没有把平面无限延伸。floor_2 仅到 x=18.0，顶部 z=1.2；landmark_4 范围 x≈16.95–17.45，并非下面这些位于 world x≈18.4、不同 y/z 的面。

## 3. 为什么会把墙拟合成水平面

实际 LiDAR 虽叫 `velodyne-VLP16`，SDF 配置是 **32 vertical ×480 horizontal**，竖直角 −30°到+15°，水平360°，10 Hz；范围噪声 Gaussian stddev=8 mm。相邻竖直束约1.4516°。初始位置到东墙水平距离约17 m，相邻扫描环的高度间距约 **0.431 m**，接近0.5 m 的 layer0 叶格边长。叶格常只有一个扫描环，而不是二维墙面点片。132 s native body 已在 world x≈16.007，距东墙约2.393 m，近水平相邻环间距约6.1 cm；同一个0.5 m叶格现在可获得多环二维墙面信息，但冻结的旧面无法利用它。

独立解析 SDF visual 盒体射线交点，使用实际 3.7–6.0 s 的 native pose、32×480束和初始化姿态配对进行离线解析采样，发现871/872/874/883叶格只出现 ring23，930/940只出现 ring25，949/950只出现 ring26。预测计数约47–53，与实际最后保存48点处于同一量级；887等因为姿态/框架/原始点缺失而预测时间和数量不同。这是机制核查，**不是原始随机噪声或建图过程的重放**。

一个固定仰角束在 x=D 竖墙的无噪声轨迹为：

`y=D*tan(azimuth)`

`z=z_lidar+D*tan(elevation)/cos(azimuth)`

它在小叶格里接近一条曲线/直线。扫描线沿 y 的变化大，跨线 z 铺展很小；8 mm 的射程噪声主要沿射线、往往增加墙法向 x 的方差。这样最小方差方向可能成为 z，而不是物理墙法线 x。报告 JSON 中有200次、seed42的独立噪声数学示例；它仅说明该机制可发生，不代表实际故障概率、仿真重放或修复成功。

数学上，对于理想沿 y 的一条线，协方差 `diag(0,0.02,0)` 的特征值是 `[0,0,0.02]`。x–z 平面里的任意向量都可作为零残差法线，x墙面与z水平面同样拟合，因此**最小特征值小不足以保证法线唯一或表示了真实二维面**。

本次真实历史谱虽然不等于严格 rank1，最小向量在非零 eigengap 下可以代数上唯一，但 `λmid/λmax≈0.0037–0.0173` 表明第二个切向方向铺展很弱。唯一向量不等于可靠的真实表面法线。应同时关注二维支撑、两个小特征值和噪声大小、eigengap及后续不同视角测量一致性。

## 4. 源码与可控后续实验

本轮冻结 `voxel_map.cpp::init_plane` 只检查 `evalsReal(evalsMin) < planer_threshold_`，实际阈值0.005 m²；`evalsMid >0.05/0.01` 仅为被注释的代码。只有线状点簇也会通过该条件。平面误差协方差公式含 `lambda_min-lambda_other` 分母，近退化谱还会影响法线不确定性；当前审计未把这一点单独定为数值崩溃，本次接受点与重建矩阵都有限。

`update_enable_` 在达到50点后变成 false，后续墙面二维信息不会改写旧面。这解释了为什么初期运动已停止、IMU初始化完成后，早期坏面仍能在130 s附近影响高度；不能简单归因于当时有剧烈动作或GPU训练。

适合根因验证的最小对照是冻结 Teacher、路线、PID、保护和传感器不变，仅分别检验：

- 用明确的二维支持/噪声相关判据拒绝近线簇建面，保留递归/无面处理；不能直接把某个 λmid 常数当通用正确值。
- 对旧面保留足够可靠的新样本进行再估计或法线一致性检查，避免刚达到点数上限就永久冻结错误面；不要无条件吸收未审核的大残差点。
- 在同一场景/起点记录早期3.7–6.0 s原始点和面成员，再比较当前坏面、高度曲线与真实墙面归属。

以上是建议的独立对照，不是本审计改动或已通过项目。回环后端可解决长期漂移，但本例有具体的前端错误高度约束；不能预设加回环会消除它。
