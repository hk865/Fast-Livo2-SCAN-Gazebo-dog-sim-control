## 当前闭环

```text
本轮 RGB 点云 / FAST-LIVO2 里程计
  → SCAN 三维路径
  → SLAM 位置与航向反馈、区域停稳判定
  → 有界机身速度、原始 IMU 保护、停车归位
  → CHAMP 步态 / 逆运动学
  → 实测关节位置与速度反馈的 effort PID
  → Gazebo Go2 动力学
```

当前没有加载机器学习运动策略。全局路线、局部规划和腿部运动控制是不同模块；更换规划器不会自动解决关节振荡。

SLAM 已用于实际位置、航向修正和纯转漂移检测。它能修正路径跟随误差；高频关节与机身平衡仍需实际关节、IMU 和接触反馈。真值只参与独立验收，不进入控制。
