独立物理审计在该段观察到行走 55.332 秒，世界 X 前进 2.551 米；纯转 14.847 秒倒退 1.938 米；零速 20.072 秒 X 仅减少 0.0162 米。净 X 进展只有 0.5966 米。45 次停止归位均收到原生 ACK 并完成，归位期实际 CHAMP 非零命令为零。损失主要发生在转向动作及行走执行期间。

实际 steering 分解显示两类因素。

- 324.665 秒第一次重新转向发生在同一条直线曲线 33 上。自开始行走，真实机身 yaw 减少约 0.399 rad，而沿实际路线的横向纠偏使 desired heading 增加约 0.169 rad，误差达到 +0.555 rad，符合严重偏离立即停车标准。
- 343.649 秒接受曲线 36 时，同一个真实 tracking pose 上新旧 desired heading 相差 −0.572 rad。规划 start state 使用当前测量滤波速度 `(-0.0655,-0.0379,0.0020)`，曲线沿弦倒退约 0.193 米、弦外横偏约 0.180 米。随后 344.251 秒重新停车；该曲线上的方向变化还导致 347.868 秒再次停车。
- 381.190 秒接受曲线 41 时，同 pose desired heading 改变 −0.415 rad，随后 381.793 秒重新停车；其当前测量速度含 −0.045 m/s 横向分量，路径横偏约 0.251 米。

因此真实身体偏航先造成跟踪损失，真实后退/横移速度又进入后续 SCAN 起始状态，部分新路线方向变化进一步触发转向。没有将这种实际身体速度误称为定位噪声，也没有用 GT 替换起始速度或方向。

三次真实 IMU 保护分别首次越过 `.30` 于 353.857、357.935、362.011 秒，均与实际 CHAMP 停止边沿相符。对应保护事件峰值为约 `.32875/.38252/.42794` rad；全部保留 `.30/.50` 门限，未放宽。它们发生在反复纯转期间，该期间有明显真实倒退。
