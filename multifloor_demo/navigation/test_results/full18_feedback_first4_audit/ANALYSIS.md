# 第四转向反馈 A/B：实际运动只读复核

基线 A 完成四个预声明区域，候选 B 在第一目标运动中因原始 IMU 倾角达到 0.50 rad 失败，未形成到达收据。两个原结果均保留；完整跨层 Demo 没有因此通过，候选姿态反馈不能据本组采用为稳定性修复。

使用 actual Adapter emit 的逐条 Twist 日志划分行走、纯转、零速，按零阶保持积分命令；原始 SLAM 和独立真值保留整数 Header 时间戳。真值只用于结果评估，采用原组件的一次初始 SE3，不用于控制。所有运动区间端点须有有界实测括号（SLAM ≤200 ms、GT ≤150 ms），不外推。两个组的所有分段端点均得到配对。命令日志的 sim 是节点缓存的浮点时钟，换成整数只为关联，不能称其为消息原生 Header 或 CHAMP 接收证据。

## B 保护时序与路线身份

原始 IMU 首次超过 0.20 rad 为 49.653 秒，正在实际行走；首次达到 0.30 rad 为 50.114 秒，Adapter 当时发出精确零速；50.127 秒收到 native zero ACK。50.170 秒达到 0.50 rad，仅在停车后 56 ms，任务失败。原活动范围中首 hold 之后所有 actual emitted command 都为零；没有将保护门限修改为另一个值，也不能据这个时序认定归位导致最初倾斜。

A 的 430 条、B 的 102 条运行中实际状态，轨迹 ID/不可变 reference 均对应真实 metadata 的当前原始 body_goal。B 只有一个 metadata 和一个 accepted path，整段同一个第一目标参考；degenerate、association reject、obstacle stop 均为 0。这排除了本次已记录链条中的旧目标混用、动态障碍停车、退化规划作为直接失败原因。A 共 11 个 metadata / 11 个 accepted path。

原组件的固定 SE3 活动最大位置误差 A 为 0.00857 m、B 为 0.00959 m，所有活动 SLAM 行均有 GT ≤150 ms 括号。两组配置只改变姿态反馈启用选项，但起始实测位置、校准航向、步态接触及后续运动历史并不完全相同，单次 A/B 不足以独立归因内部姿态反馈环节。Sim 负责原生 JTC/关节/足接触进一步审计。本报告不重复解释未观测的执行器内部状态。

A 第四段保守起点为第三个原生 receipt 结束 109.7 秒、终点 actual terminal 141.763 秒；原始 IMU、measuredJoint、JTC 和四足 CDR 整段覆盖由物理 owner 的专项收据判定。B 根本没有进入第四段，不能标记第四段覆盖通过。
